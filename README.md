# Polite Mail Skill (情緒排毒商務信)

把氣到發抖、滿篇國罵的客訴草稿，一秒轉成無懈可擊、字字帶刀的得體商務信。

保留 100% 賠償訴求與最後期限，拔除 100% 情緒毒素。

---

## 1. 解決什麼問題？

人在暴怒時發信，通常會踩到 3 個坑：
1. **被對方轉移焦點**：抓著你的髒話做文章，掩蓋他們原本的失職。
2. **喪失法律制高點**：情緒性恐嚇無法當作有效舉證，甚至反吃公然侮辱。
3. **訴求被稀釋**：通篇都在發洩，對方根本不知道你具體要賠多少、幾點前要處理。

市面上的 AI 潤飾通常走向另一個極端——直接把你改寫成「抱歉造成您的困擾」的討好自責信。

**本 Skill 核心原則：**
- 拔除全部髒話與非理性發洩。
- 100% 保留金額、受損事實與截止期限，絕不妥協退讓。
- 把「告死你」自動轉化為「行政院消保申訴 / 存證信函催告 / 民刑事違約訴訟」。
- 自動標記缺漏資訊（如漏附的訂單號碼、合約條款、確切金額）。

## 2. 轉化光譜 (Spectrum 1-10)

直接指定數值即可切換語氣強度：

| 級距 | 模式名稱 | 適用情境 | 風格特徵 |
| :--- | :--- | :--- | :--- |
| **Level 1-3** | 🕊️ 溫和協商派 | 內部跨部門同事、重要老客戶 | 留足台階、修復關係、語氣委婉但清楚交代問題與責任邊界 |
| **Level 4-7** | ⚖️ 商務平衡派 (預設) | 一般廠商對接、進度催繳、常態客訴 | 公事公辦、不亢不卑、理性中立、條理分明 |
| **Level 8-10** | ❄️ 冰冷施壓派 | 惡意拖延賴帳、詐欺侵害、最後通牒 | 字字得體挑不出毛病、句句如冰刀、寸步不讓、錨定法律程序 |

## 3. 實戰轉化範例：裝潢統包爛尾與坐地起價

### 🔴 原始粗暴輸入 (Raw Angry Draft)
```text
幹！你們這群死吸血鬼到底是在裝潢還是拆家？
當初簽約白紙黑字寫好三個月完工，現在都第五個月了，現場磁磚貼得歪七八糟、油漆滴到我新買的實木地板，衛浴管線還漏水把樓下天花板搞得一塌糊塗！
今天早上居然還有臉傳訊息跟我說要追加 25 萬「非預期材料費」？真他媽笑死人，你們工班整天在現場抽煙嚼檳榔打手遊，根本是在洗產地騙錢！
我警告你，這星期五下午五點前沒把漏水給我修好、地板給我換新、現場垃圾清乾淨，一毛尾款你們都別想拿！敢再跟我提加價 25 萬，我直接帶消保官跟建管處去抄你們公司，順便找律師告你們詐欺背信，讓你們在裝潢界混不下去！
```

### 🟢 Skill 輸出成果 (設定：Level 9 ❄️ 冰冷施壓派)

#### 🧯 1. 情緒排毒與事實提煉
- **原始情緒痛點**：工期嚴重逾期 60 天、現場工藝粗糙造成地板毀損與樓下漏水受災、承攬方無故惡意追加 25 萬元費用、施工現場管理渙散。
- **客觀事實歸納**：
  1. 依約應於三個月內完工，現已逾期達兩個月；
  2. 現場存在磁磚不平整、油漆污染實木地板，以及衛浴管線滲漏致第三人受害之重大瑕疵；
  3. 承攬方未經雙方事前書面簽署工程變更單，逕行提出 25 萬元額外費用要求。

#### 🎯 2. 核心訴求與保全清單
- **要求事項**：
  1. 完成衛浴管線滲漏之根本修復，並全額承擔樓下住戶之修繕賠償責任；
  2. 更換受漆漬污染毀損之實木地板；
  3. 清運現場施工廢棄物，恢復整潔；
  4. 撤回未符契約程序之 25 萬元追加款項。
- **約束期限**：本週五（[2026/10/24]）17:00 前。
- **升級途徑**：暫扣全部工程尾款；正式向主管機關及行政院消保會提出消費爭議申訴；委請律師就民事債務不履行損害賠償與刑事詐欺背信責任啟動訴訟。

#### ⚠️ 3. 關鍵資訊待補提示
- `[請補充：工程合約編號 / 房屋施工地址 / 統包公司正式名稱 / 原定完工日期]`

#### 📌 4. 建議信件主旨
- **主旨 A（嚴正通牒）**：【工程限期改善催告函】關於 [房屋地址] 室內裝修工程嚴重逾期、施工瑕疵及爭議款項之最後履約通知 (合約編號：[請補充])
- **主旨 B（行動導向）**：【正式通知】限期排除重大瑕疵暨暫停追加款爭議主張通知

```text

本信係針對雙方於 [合約簽署日期] 就座落於「[房屋地址]」所簽訂之室內裝修工程合約（合約編號：[請補充]）之履行狀況發出正式通知。

依合約第 [X] 條明訂，本案工程期限為三個月，應於 [原定完工日] 前全數完工交付。惟截至今日，工期已實質逾期達兩個月，且經現場查核，存在下列未達驗收標準之重大瑕疵與違約情事：

1. 重大管線瑕疵與第三人損害：衛浴管線施工不良導致滲漏水，已造成樓下住戶天花板受損，涉及民事侵權與公共安全疑慮；
2. 建材毀損與工藝瑕疵：地坪磁磚鋪貼明顯不整，且施工防護不當，導致油漆大面積沾染並損壞我方新購之實木地板；
3. 無效之追加款主張：貴司於今晨提出追加「25萬元材料費」之要求，未符雙方合約第 [Y] 條關於「工程變更須事前以書面簽認」之約定程序，我方歉難同意並予駁回。

為確保雙方合約權益並使本工程得以推進，特此正式催告：
```

## 4. 三步驟快速上手 (How to Use)

1. **安裝 Skill**：將本倉庫的 `SKILL.md` 複製至你目標專案的 `.agents/skills/polite-mail-skill/SKILL.md`，或 Antigravity 全域技能目錄。
2. **貼上暴怒草稿**：在對話視窗直接輸入你的草稿。
3. **指定強度指令**：
   > 「請參考 polite-mail-skill，用 Level 9 幫我把這段草稿轉成正式信件。」
